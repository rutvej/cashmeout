# Screen 3: Goal Setup (`specs/screens/03-screen-goal-setup.md`)

## 1. Purpose & User Objective
On this screen, the player reviews and calibrates their life goals before beginning active simulation. Goals are split into:
1. **Recurring Life Goals:** Continuous Emergency Shield and Flexible Annual Vacation (Domestic vs International packages).
2. **One-Time Life Milestones:** Fixed target dates (Car at 27, Wedding at 29, Home at 34, Child College at 46, Retirement at 60).

### Onboarding Flow Choice & Default 100% Bank Accumulation
Rather than forcing a linear sequence that obligates every player to navigate the detailed financial setup sheet before playing, this screen concludes with an **instant two-way fork**:

1. **⚡ Start Simulation Instantly (Default to Bank Cash):**
   - **Zero Friction Onboarding:** All goals are initialized with **`baseMonthlySIP = 0`** (`allocationPercent = 0`, `effectiveMonthlySIP = 0`).
   - **100% Liquid Cash Accumulation:** 100% of monthly surplus flows directly into the player's Bank Account (`character.liquidCash`) every month.
   - **Live Clock:** Sets `simulation.isPaused = false` and navigates directly to `MainGameScreen` (`currentScreen: 'main_game'`), starting the simulation clock ticking immediately.
   - Players can later allocate monthly SIPs or make lump-sum seed transfers from accumulated bank cash at any time mid-game.
2. **⏸️ Pause & Plan Allocations First:**
   - Sets `simulation.isPaused = true`.
   - Transitions to Screen 4 (`financial_setup`), allowing the player to calibrate ₹ Amount or % Percentage SIPs and assign investment instruments before unpausing.

## 3. Data Contract

### A. Inputs (Read from Store)
- `character: CharacterState` (from store)
- `goals: GoalItem[]` (auto-generated by `generateInitialGoals(character)`)

### B. Outputs (Mutations on State)

#### Branch 1: "⚡ Start Simulation Instantly" (Frictionless Start)
```typescript
// Initial state initialization for instant play
goals.forEach((goal) => {
  goal.baseMonthlySIP = 0;
  goal.allocationPercent = 0;
  goal.effectiveMonthlySIP = 0;
  goal.instrumentId = goal.instrumentId || 'savings';
});

// Store mutations:
gameState.goals = goals;
gameState.simulation.isPaused = false;
gameState.currentScreen = 'main_game';
```
- **Surplus Rule:** $\text{Leftover Surplus} = \text{monthlySurplus} - 0 = \text{monthlySurplus}$. 
- 100% of the character's surplus is deposited into `character.liquidCash` on every monthly tick.

#### Branch 2: "⏸️ Pause & Plan Allocations First" (Deliberate Planning)
```typescript
// Maintain paused state for planning
gameState.goals = goals;
gameState.simulation.isPaused = true;
gameState.currentScreen = 'financial_setup';
```

## 4. UI Controls & User Interactions

1. **Top Context Bar:**
   - Displays character name, current age, and current monthly surplus: `₹XX,XXX / mo`.
   - Clarifies that the player can start immediately (accumulating bank cash) or customize allocations now.

2. **Goal Card Elements:**
   - **Icon & Title:** Identifies the life milestone.
   - **Badge:** `[MANDATORY]` (Emerald) or `[OPTIONAL]` (Slate). Mandatory goals cannot be toggled off.
   - **Target Amount Display:** Formatted in INR (e.g. `₹8,00,000` or `₹1.58 Cr`).
   - **Deadline Tag:** Target age, years remaining, and months countdown.

3. **Trip Package Switcher:**
   - On the Annual Vacation card, toggle between:
     - `Domestic` (e.g., ₹50,000)
     - `International` (e.g., ₹1,50,000)
   - Toggling updates `targetAmount` and `selectedTierOption`.

4. **Action Choice Buttons (Cred NeoPOP Light Styling):**
   - **"← Back to Profile"**: Text link/pill returning to `spawn_reveal`.
   - **"⚡ START SIMULATION INSTANTLY" (Primary CTA):**
     - NeoPOP high-contrast card button: Emerald background (`#10B981` / `#059669`), crisp black 2px border, 3px solid hard drop-shadow.
     - Headline text: `⚡ START SIMULATION INSTANTLY` (Bold, uppercase).
     - Subtitle text: `100% Surplus to Bank Cash • Clock Starts Now`.
     - Clicking immediately transitions to Screen 5 (`main_game`) with `isPaused = false`.
   - **"⏸️ PAUSE & PLAN ALLOCATIONS FIRST" (Secondary Option):**
     - NeoPOP outlined card button: Light slate/amber accent, 2px border, 3px hard drop-shadow.
     - Headline text: `⏸️ PAUSE & PLAN ALLOCATIONS FIRST`.
     - Subtitle text: `Set ₹ Amount or % SIPs & Vehicles Before Starting`.
     - Clicking transitions to Screen 4 (`financial_setup`) with `isPaused = true`.

## 5. Exit Criteria & Navigation

| Action Selected | Destination Screen | `simulation.isPaused` | Goal SIP Setup |
| :--- | :--- | :--- | :--- |
| **⚡ Start Instantly** | Screen 5 (`main_game`) | `false` (Running) | All goals `baseMonthlySIP = 0`; 100% surplus flows to Bank Cash |

| **← Back** | Screen 2 (`spawn_reveal`) | Unchanged | No mutations |
